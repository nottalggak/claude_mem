# 가구 공장 디지털 트윈 — 리서치 종합 보고서 및 실행 계획

작성일 2026-10-10. 다음 주 화요일 실제 가구 공장 방문 전에 "공장 전체를 온라인에 그대로 복제하고, 병목·비효율·설비 투자·레이아웃·인력 배치·동선 개선안을 숫자로 내놓는" 일을 어떻게 할지 정리했다. 리서치 원문 6건은 `docs/research/`에 있고, 이 저장소에는 **지금 바로 돌아가는 프로토타입**(데이터 스키마 → SimPy 시뮬레이션 → 브라우저 3D 트윈)이 들어 있다.

## 1. 결론 요약

1. **NVIDIA Omniverse는 목표가 아니라 선택 레이어다.** Omniverse는 2026년 5월부터 개발·운영 무료로 바뀐 것으로 보도되지만(1차 출처 확인 필요) RTX 16 GB급 GPU와 Kit SDK 학습이 필요하고, 결정적으로 **이산사건 시뮬레이션(DES) 엔진이 없다**. 병목·처리량·리드타임 질문에 답하는 것은 DES다. 따라서 핵심은 "Python DES + 2.5D 파라메트릭 레이아웃 + 브라우저 3D"이고, OpenUSD로 내보내 두면 나중에 Omniverse에서 포토리얼·AMR 검증을 얹을 수 있다.
2. **"똑같이 복제"의 현실적 정의**: (a) 벽·기둥·구역·기계 위치와 외형(±5~15 cm), (b) 모든 기계의 명판 사양·사이클타임·셋업·고장률·전력, (c) 제품별 라우팅·BOM·주문 패턴, (d) 작업자·대차·지게차의 실제 동선, (e) 집진기·컴프레서를 포함한 전력 프로파일. 이 다섯 가지가 `factory.json` 하나에 들어가면 시뮬레이션과 3D가 동시에 만들어진다. 포토리얼 외관은 가우시안 스플랫(Scaniverse → Spark) 한 겹으로 해결한다.
3. **상용 시뮬레이터(Plant Simulation, FlexSim, AnyLogic)는 연 800만~2,500만 원/석이며 무료판은 상업 사용 불가**. 자체 SimPy 엔진(라이선스 0원)을 쓰고, 업종 템플릿(런닝쏘→엣지→보링→조립)을 만들어 2호 공장부터 재사용하는 것이 "많은 공장에 파는" 구조다.
4. **하루 방문에서 가장 가치 있는 데이터는 사진·스톱워치·인터뷰·고정 카메라 영상이다.** LiDAR 스캔은 레이아웃 기하에만 쓰고, 기계 3D는 박스+사진으로 충분하다. 장비 신규 지출은 100~130만 원 안에서 끝난다.
5. **돈은 정부 매칭에서 나온다.** 중소 가구공장의 자부담 지불 상한은 500만~2,000만 원(추정). 정부형 스마트공장(회당 최대 2억), 경기도형(70%, 최대 5천만~1.2억), 제조AI특화(2억, 50%), 데이터바우처(4,500만), AX 바우처를 묶어 **공급기업**으로 사업비를 받는 구조가 현실적이다. 2026년 공고는 대부분 마감 → 지금 할 일은 공급기업 Pool 등록 준비와 2027년 1~3월 공고 대비 수요기업(첫 공장) 매칭.
6. **"누구를 자르고 누구를 뽑을지"는 "재배치·교육·채용 우선순위"로 프레이밍해야 한다.** 근로기준법 제23·24조, 개인정보보호법(작업자 위치 데이터), AI기본법(2026-01) 때문이고, 현장 반발로 데이터 수집 자체가 막히기 때문이다. 집계는 공정·역할 단위로만.

### 샘플 공장 시나리오 결과 (가상 데이터, 5 seed 평균) — `sim/out/comparison.md`
수요를 설비능력 이상(13 주문/일)으로 둔 베이스라인에서 병목은 반자동 엣지밴더(가동률 85%)였다. 시나리오별로:
- 재단 CNC 1대 추가(8,500만 원): 처리량 +2%, 리드타임 −5%, 병목은 엣지밴더로 유지 → **투자 대상이 틀렸음을 사전에 보여주는 예**.
- 배치 크기 절반(투자 0): 처리량 +14%, 리드타임 −26%, 대신 운반거리/제품 +89%, WIP(배치 수) 증가 → 운반 인력·대차가 다음 제약.
- SMED 셋업 단축(300만 원): 리드타임 −6%, 회수 0.4년 → **가장 먼저 할 일**.
- 엣지밴더 자동기 교체 + CNC 추가(1.45억): 리드타임 −12%, WIP −10%, 병목이 조립으로 이동.
숫자 자체는 가상이지만, 보고서가 **"어떤 기계를 사면 병목이 어디로 옮겨가는지"**와 **회수기간**까지 한 표로 내놓는 형식이 그대로 제안서가 된다.

## 4. 화요일 방문 — 핵심만
- 역할 4개: 스캔 / 360·측정·명판 / 공정·전력·인터뷰 / 카메라·동선. 시간표·장비·체크리스트·동의서 양식은 `docs/01_현장방문_체크리스트.md`.
- **필수 15개 항목**(LiDAR 세그먼트, 제어 치수 15개, 평면도, 기계별 명판·사진·치수, 집진기·컴프레서 카운터, 분전반·고지서, 클램프 전류, 사이클타임 5회+, WIP 스냅샷, 고정 카메라 영상+동의서, 지게차 경로, 인터뷰, 360 영상, BOM 4~8종, 3개월 주문이력).
- 사전 요청 서류: 세움터 건축물현황도(소유자 발급), 설비목록, 단선결선도, 12개월 전기요금, 작업일보·출하일지·불량일지 3개월, BOM, 네스팅 출력물.
- 방문 후 48시간: 템플릿 → `factory.json` → 베이스라인 시뮬이 현장 출하량·WIP ±10% 안에 들도록 보정 → 사장에게 1장 요약.

## 5. 가구 공장 도메인 기본값 (리서치 3) — 방문 전 모델 초기치
- 판재가구 흐름: 판재 입고 → 재단(런닝쏘 1.5~4분/시트, CNC 네스팅 6~12분 기계+핸들링 10~20분/시트) → 엣지밴딩(12 m/min, 600 mm 1변 6~8초, 4변 부품 40~90초, 수작업 리턴 시 실효 처리량 기계능력의 40~60%) → 보링(CNC 20~60초/부품, 다축 보링 셋업 10~30분) → 하드웨어 → (도장 1~2분/면 + 건조 4~24h) → 조립(수납장 10~30분) → 포장(3~8분) → 출하.
- 전력: 집진기 15~55 kW, 컴프레서 15~37 kW가 상시 → 오리건 캐비닛 공장 사례 집진이 전력 50%, VFD로 1/3 절감.
- 전형적 병목: ① 엣지밴더(핸들링) ② 도장·건조 WIP ③ 수작업 운반 ④ 판재 피킹 ⑤ 다축 보링 셋업 ⑥ 키트 완결 대기 ⑦ 종이 작업지시.
- 개선 레버와 기대치: 리턴컨베이어(+30~60% 처리량), 배치1/오더 흐름(리드타임 −30~60%), SMED(셋업 −50%), 레이아웃(이동거리 −20~40%, 단 재배치만으론 총 제조시간 거의 불변이라는 연구도 있음), 집진 VFD(전력 −30%).
- KPI·분석: OEE, 택트 vs 사이클, Little's law(WIP = 처리량 × 리드타임)로 모델 검증, VSM, 스파게티, SLP/CRAFT, M/M/1·Kingman(가동률 85% 넘으면 대기 폭증)으로 2호기 효과 정량화.

## 6. 사업화 (리서치 5)
- 공백: 50인 미만 판재가공 공장에 수천만 원대로 레이아웃·병목 시뮬레이션을 해주는 전문 플레이어가 비어 있음. 플랫폼형(이에이트·버넥트)·대기업 SI는 비싸고, KPC·TP는 정량 시뮬레이션이 약함.
- 패키지: P0 현장 진단(300~800만, 첫 1~3개사 무료) → P1 트윈+개선안(3,000~8,000만, 정부 매칭) → P2 구현 동반(사업비 1~2억의 30~50%) → 구독(월 50~150만, 전기요금 절감분으로 상쇄).
- 경로: 사업자 업종 추가 → smart-factory.kr 공급기업 Pool 모집 모니터링(기존 MES 공급기업과 협업체 병행) → 2027년 1~3월 정부형·경기도형·상생형 AI트랙·데이터바우처·AX바우처 동시 매칭 → 공급기업 역량진단 Level 3- → 전문기업 지정.
- 첫 레퍼런스: "무료 P0 + 성과 공개 동의" 계약, 경기도 디지털전환 견학공장(최대 2,000만, 90%) 등록, 스마트공장 수준확인(상시)으로 공식 Before/After.
- 제안서 지표: 리드타임, 병목 가동률, 인당 판재 처리량, 셋업·잔업 시간, 엣지 불량 재작업률, 보행거리·지게차 교차점, 최대수요전력·kWh/장·18~21시 최대부하 비중, 투자 회수기간, 납기준수율.
- 전기요금: 2026년 산업용(을) 계절·시간대 개편(낮 −16.9원, 밤 +5.1원, 봄·가을 주말 낮 50% 할인, 18~21시 최대부하) → 잔업 시간대·집진기 기동 순서 스케줄링이 돈이 된다.

## 7. 리스크와 미확인 사항
- 리서치 중 외부 사이트 직접 열람이 상당수 차단되어 **[확인 필요]** 표시 항목(정부 지원 비율·한도 원문, 한전 요금표 원문, E-9 쿼터, Omniverse 라이선스 원문, 중고 기계 시세)은 공고 원문·요금표에서 재확인해야 한다.
- iPhone LiDAR는 긴 복도·큰 홀에서 드리프트가 누적된다(연구 RMSE 10~56 cm). 세그먼트 분할 + 레이저 제어점 정합이 필수.
- 추적 라이브러리(Ultralytics·BoxMOT)는 AGPL. 서비스로 배포하려면 Apache 검출기 + 자체 트래커로 대체하거나 상용 라이선스.
- 인력 관련 산출물은 법·윤리 리스크 → 재배치·교육 중심 프레이밍, 개인 식별 금지.
- 샘플 수치는 전부 가상이다. 현장 측정으로 교체 전에는 절대값을 외부에 쓰지 말 것.
