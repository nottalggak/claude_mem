## 3. 데이터 체크리스트

### 필수 (빠지면 → 트윈에서 추정으로 남는 부분)
- [ ] 전체 홀 LiDAR 세그먼트 ≤150㎡ 단위 (LAS+GLB), 세그먼트 지도, 루프 클로저 (→ 레이아웃 기하)
- [ ] 레이저 제어 치수 15개 이상: 대각선, 기둥 간격, 천장고, 문 폭 (→ 스캔 정합·스케일)
- [ ] 건축물현황도/준공 평면도 (→ 벽·기둥 기준 좌표계)
- [ ] 기계별 폴더: 명판·전체·측면·HMI 사진, 세그먼트 번호, 외형 L×W×H, 입출력 버퍼 위치 (→ 기계대장 시트 2)
- [ ] 집진기·컴프레서 명판, 설정 압력, 가동/로드 시간 카운터 2회, 덕트 경로 (→ 부대설비 전력 20~50%)
- [ ] 분전반·수변전 사진, 변압기 kVA, 계약전력, 12개월 고지서 (→ 에너지 모델 보정)
- [ ] 3.7 kW 이상 기계 클램프 전류 정지/공회전/가공 (→ 부하율·대기전력; 당일 불가 시 D0)
- [ ] 공정 순서도 + 병목 후보 스테이션별 사이클타임 10회 이상(핸들링 분리) + 셋업 1회 전과정 + 작업자 수 (→ 시뮬레이션 핵심 파라미터)
- [ ] WIP 스냅샷 2~3회 (위치·대차 수·부품 수) (→ Little's law 검증)
- [ ] 고정 카메라 3대 종일 녹화(08:00 전 시작) + 2주 유지, 동의서 완료 (→ 대기열·게이트·동선)
- [ ] 지게차/대차 주요 경로·왕복 횟수, 자재 입출고 위치 (→ 운반 모델)
- [ ] 인터뷰 기록(시트 12) + 서류 목록 합의
- [ ] 360 영상 전체 통로 1회 이상 (→ 시각 레이어·기계 참고)
- [ ] 제품 4~8종 BOM (부품 치수·엣지 변 수·홀 수·도장 여부) (→ 라우팅·가공시간)
- [ ] 3개월 주문/출하 이력 (→ 도착 분포·믹스·납기준수율)

### 권장
- [ ] 기계별 360° 근접 오브젝트 스캔, 포토그래메트리 사진 세트 (→ 기계 3D 스탠드인)
- [ ] 느린 360 워크 2회 (→ 가우시안 스플랫 배경)
- [ ] 파워플래너/한전ON 15분·시간별 export — v1 전력 기준의 **필수** 출처, 방문 전 소유자가 지사에 서면 요청 (→ 피크 분석)
- [ ] 워크샘플링 2시간, 스파게티 2개, REBA 자세 사진 (→ 인력 재배치 근거)
- [ ] PLC/네트워크 스위치 모델·IP 라벨, OPC UA/tapio/SOPHIA 접근 가능 여부 (→ 실시간 연동 단계)
- [ ] 랙·대차·팔레트·자재 번들 치수 (→ 재사용 에셋)
- [ ] 소음·조도 스팟 측정 (→ 환경 레이어)

## 4. 스캔 프로토콜 요약
1. 홀을 ≤150㎡ 세그먼트로 나누고 각 세그먼트를 바닥 마커(번호 테이프 "+")에서 시작·종료(루프 클로저).
2. 1 m/s 이하로 걷고 표면에서 1~1.5 m, 가슴 높이에서 위아래 스윕. LiDAR 유효 범위 ~5 m → 천장 트러스는 사진·360으로 대체.
3. 대형 기계는 별도 오브젝트 스캔(360° 두 바퀴, 높낮이 다르게) + 사진 10~20장.
4. 조명 전부 켜기, 창/천창 향해 스캔 금지, 광택 라미네이트·유리는 사진으로 보완, 세그먼트마다 렌즈 닦기.
5. 세그먼트 0.5~2 GB → 점심·휴식 때 백업. 폰 2대 교대로 발열 관리.
6. 3,000㎡ ≈ 20 세그먼트 ≈ 스캐너 1명 2.5~3시간 → 2명 병행.
7. 기대 정확도: 세그먼트 내 ±2~5 cm, 제어점 정합 후 전체 ±5~15 cm. 레이아웃·간격 판단에는 충분, CAD급 아님.

## 5. 인터뷰 질문 (사장·반장)
1. 주력 제품군과 월 생산량, 주문 방식(수주/재고), 평균 리드타임
2. 공정 순서와 병목은 어디, 왜
3. 기계별 하루 가동시간, 교대, 월 가동일, 휴식
4. 가장 자주 바뀌는 세팅(두께·엣지·색)과 교체 시간
5. 자재가 어디에 쌓이나(WIP 위치), 랙·대차 수
6. 지게차·대차 대수, 운전자, 경로, 하루 이동 횟수
7. 불량·재작업 비율과 원인, 폐기 처리
8. 집진기·컴프레서 가동 패턴, 월 전기요금, 계약전력
9. ERP/MES/엑셀 기록 형식, 받을 수 있는가
10. 안전·출입 통제·촬영 금지 구역
11. 향후 변경 계획(기계 추가·레이아웃)
12. 작업자 수, 숙련 구분, 외국인 비율, 잔업 패턴
13. **돈 질문 3개**: 올해 가장 비쌌던 비용은? 납기 못 맞춘 횟수와 손해는? 사고 싶은 기계와 망설이는 이유는?
14. 정부 스마트공장 사업 수혜 이력(중복 지원 제한 확인), 스마트공장 수준확인 여부

2. `python3 sim/factory_sim.py data/<공장>.json` 후 `python3 sim/validate.py sim/out/baseline/kpis.json sim/out/baseline/factory.json` → 시트 18에서 변환된 `observations.validation`(§1.2 v0.5 기준)과 대조, 실패 항목은 명세서 §8 순서로 보정. 시나리오 비교는 그 다음(`sim/compare.py`)
3. CloudCompare로 세그먼트 정합 → 평면 래스터 → 기계 좌표 검증
4. 사장에게 1장 요약(병목·리드타임·전력) 송부, 2주 로깅 일정 확정
