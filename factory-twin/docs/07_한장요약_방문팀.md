# 한 장 요약 — 화요일 방문팀용 (전체는 `03_공장복제_명세서.md`)

**우리가 만드는 것**: 같은 주문을 넣으면 같은 출하·재공·대기·동선·전력이 나오는 모델. 기하가 아니라 **행동**을 복제한다.

**합격 기준(v0.5 진단)**: 2주 출하 ±10% · 생산 리드타임 평균 ±15% · 납기준수율 ±5%p · WIP ±20% · 가동률 ±5%p(엣지밴더 ±10%p) · 병목 1위 빈도 ≥80% · 전력 2주 ±10%. 입력에 쓴 데이터로 검증하지 않는다(배치 추적·센서스·게이트 카운트는 검증 전용).

**증거의 분담**: 하루 방문 = 기하·사양·규칙·수작업 요소·검증용 관측 / 2주 로깅(기계별 CT·광전 카운터·카메라 3대) = 사이클·셋업·전력·대기열 / 3~12개월 기록(재단표·발주서·시공캘린더·세금계산서) = 도착·믹스·라우팅·외주·고장 빈도.

**결론을 흔드는 것 순서**(세 체제 모두): ① 배치 묶음·투입 규칙(반장 인터뷰·재단표) ② 병목 후보 2~3대의 실효 사이클(핸들링 포함, ±10%) ③ 셋업 빈도(성수기)·수리시간(비수기)·운반 속도. 기계 외관 정밀도는 하위.

**반드시 가져올 15개**: LiDAR 세그먼트+제어 치수 15개 / 평면도 / 기계별 명판·사진·작업 영역·이동 등급 / 집진·컴프레서 카운터 2회 / 분전반·고지서 / 클램프 3점(정지·공회전·가공) / 병목 후보 시간연구 10회(가공·핸들링 분리, 부품 치수) / 셋업 1회 전과정 / WIP 센서스 3회 / 배치 추적 2~3건 / 카메라 3대 종일+2주 / 지게차·대차·탑차 대장 / 인터뷰(규칙은 "만약 ~면 ~한다") / BOM 4~8종 / 3개월 주문·출하 이력.

**하지 말 것**: 카탈로그 속도를 사이클로 / 셋업 시간만 재고 빈도 무시 / 표준 공정도를 라우팅으로 / 반장을 근무 중 빼내기(휴식·종업 후만) / 협의·동의 없는 촬영 / 완료 시각만 있는 기록으로 대기·가공 분리 시도.

**무엇이 무엇을 잡는가**(03 §10.3): 사이클 ↔ 그 기계의 가동률(CT 로그) / 운반 ↔ 운반자 가동률·카메라 왕복 횟수 / 배치 규칙 ↔ 셋업 횟수·재단표 / 수리시간 ↔ 설비이력. 처리량·리드타임 평균만으로는 아무 파라미터도 식별되지 않는다 → 시트 2·4·13·17·23 을 비우면 보정이 불가능하다(시트별 영향은 `08_시트_파라미터_KPI_지도.md`).

**당일 꼭**: "앞으로 2주가 평소보다 한가한가"(한가하면 구조 검증 불가), 화이트보드·대차 사진 08:00·15:30, 출근부 3개월, 재단표 발행 시각·순번, 최초/최종 시공일. 납품 후는 `09_트윈_유지_프로토콜.md`(하루 3분 + 주 10분 신호 7개).

**역할**: L 리드·인터뷰 / F 흐름(배치 추적·센서스·게이트) / T 시간·OEE / S1·S2 측량. 카드는 `05_역할별_현장카드.md`. 시트는 `현장수집_템플릿.xlsx` 0~24.

**방문 후 48시간**: xlsx → `tools/templates_to_json.py` → `sim/factory_sim.py` → `sim/validate.py`(시트 18) → 실패 시 구조→시간→변동→규칙 순 보정 → `sim/sensitivity.py` 상위 10개 = 2주 로깅 재측정 목록 → 사장에게 1장(병목·리드타임·전력·불확실 목록).

**권고의 기준**: 복제 검증 통과 후에만. P(개선) ≥ 0.9(모든 체제), 95% 구간이 0을 안 걸침, CAPEX 안은 p10 회수 ≤ 36개월. 레이아웃은 거리 15~35%를 줄이지만 처리량은 거의 안 변한다 — 처리량은 병목 설비·규칙에서 온다.
