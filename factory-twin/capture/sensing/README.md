# 2주 비침습 로깅 키트 (≈50만 원) — 운영 요약
근거·세부: `docs/03_공장복제_명세서.md` §6, `docs/research/09_records_mining_and_sensing.md` §3.

| 구성 | 역할 |
|---|---|
| Shelly Pro 3EM-120A (주 피더) | 1분 kW/kWh, 한전 15분 데이터와 대조 |
| ESP32 + SCT-013-030 ×8 (`esphome_ct_clamp.yaml`) | 기계별 1상 전류 1 Hz → 정지/공회전/가동, 사이클 수, 셋업 간격 |
| 광전 센서 ×2 | 엣지밴더 투입구·포장 부품 카운트(전류로는 부품 수 불가) |
| Raspberry Pi 4 + SSD (`mqtt_logger.py`, chrony NTP) | Mosquitto + SQLite, 모든 센서·카메라의 시계 기준 |
| 카메라 3대 | 버퍼 구역 대기열 카운트, 게이트 라인 크로싱, 기계 ROI 움직임 (기기 내 처리, 원본 2주 후 삭제) |

절차: D0 전기기사 설치·차단기↔기계 라벨 → D1 기계별 정지→공회전→1사이클 라벨링(벽시계 기록) → 임계값 학습(`states_from_current.py`) → D1~14 로깅 → 매일 1회 동기 이벤트(카메라 앞에서 기계 ON) → 주 1회 백업.
주의: 엣지밴더는 글루포트 히터·이송 모터가 대기 중에도 돌아 전류만으로 가공 판별이 약함 → 트리밍 모터 채널 또는 광전 카운터 병행. 단일 피더에서 기계를 분해(NILM)하는 것은 2주 과제로는 불가 → 기계당 CT 1개.
